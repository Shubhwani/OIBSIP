1.1 Handle Missing Values & Inconsistent Data¶

  • Rows with a missing CustomerID can't be attributed to any customer, so they're dropped (they're typically guest checkouts anyway and useless for per-customer segmentation).
  • Rows with missing Description are kept (description isn't used downstream) but noted.
  • Cancelled orders are invoices whose InvoiceNo starts with "C" — these represent returns and have negative Quantity. We drop them for RFM purposes since they're not genuine purchases.
  • Rows with UnitPrice <= 0 are data-entry errors and are removed.
  • Exact duplicate rows are dropped.

3. Feature Selection — RFM Analysis¶

We use the classic RFM framework, which captures purchasing behaviour in just 3 numbers per customer and is the standard basis for e-commerce segmentation:

  • Recency (R): days since the customer's last purchase (lower = more engaged)
  • Frequency (F): number of distinct orders placed (higher = more loyal)
  • Monetary (M): total amount spent (higher = more valuable)
In [12]:
snapshot_date = df["InvoiceDate"].max() + pd.Timedelta(days=1)

rfm = df.groupby("CustomerID").agg(
    Recency=("InvoiceDate", lambda x: (snapshot_date - x.max()).days),
    Frequency=("InvoiceNo", "nunique"),
    Monetary=("TotalPrice", "sum"),
).reset_index()

4. Standardise Features Before Clustering¶

K-Means is distance-based, so features on different scales (days vs. counts vs. currency) would distort distances. Monetary and Frequency are also right-skewed, so we log-transform them first, then apply StandardScaler to give every feature mean 0 / std 1.

In [15]:
rfm_log = rfm.copy()
rfm_log["Frequency"] = np.log1p(rfm_log["Frequency"])
rfm_log["Monetary"] = np.log1p(rfm_log["Monetary"])

features = ["Recency", "Frequency", "Monetary"]
scaler = StandardScaler()
rfm_scaled = scaler.fit_transform(rfm_log[features])
rfm_scaled = pd.DataFrame(rfm_scaled, columns=features, index=rfm.index)

5. K-Means Clustering — Choosing K with the Elbow Method¶

We fit K-Means for K = 1..10 and plot inertia (within-cluster sum of squares). The "elbow" — where adding another cluster stops giving a big drop in inertia — is a good candidate for K.

In [16]:
inertias = []
K_range = range(1, 11)
for k in K_range:
    km = KMeans(n_clusters=k, random_state=42, n_init=10)
    km.fit(rfm_scaled)
    inertias.append(km.inertia_)

plt.figure(figsize=(7, 4.5))
plt.plot(list(K_range), inertias, marker="o")
plt.xlabel("Number of clusters (K)")
plt.ylabel("Inertia (within-cluster SSE)")
plt.title("Elbow Method for Optimal K")
plt.xticks(list(K_range))
plt.tight_layout()
plt.show()

def label_cluster(row):
    if row["Frequency"] >= cluster_profile["Frequency"].median() and row["Recency"] <= cluster_profile["Recency"].median():
        if row["Monetary"] == cluster_profile["Monetary"].max():
            return "Champions (high value, frequent, recent)"
        return "Loyal customers (frequent, engaged)"
    if row["Recency"] > cluster_profile["Recency"].median() and row["Frequency"] <= cluster_profile["Frequency"].median():
        return "At-risk / churned (haven't bought in a while)"
    return "New / one-time buyers (low frequency, low history)"

9. Insights & Recommended Marketing Actions¶

(Exact numbers depend on the run above — re-read the cluster profile table before finalising wording for your submission.)

Segment Typical profile Recommended marketing action
Champions Low recency, high frequency, high monetary Reward with a VIP/loyalty programme, early access to new products, referral incentives. Protect this segment — it's the most profitable, don't over-discount to them.
Loyal customers Moderate–high frequency, decent spend, fairly recent Upsell/cross-sell complementary products, personalised recommendations, loyalty points to nudge them toward Champion status.
At-risk / churned High recency (haven't purchased in a long time), low frequency Win-back email campaigns, time-limited discount codes, "we miss you" messaging, ask for feedback on why they stopped buying.
New / one-time buyers Low frequency (often just 1 order), variable recency Onboarding email sequence, second-purchase discount, retargeting ads to convert them into repeat customers before they churn.

General takeaways:

  • The clusters show a clear divide between high-frequency/high-spend customers and low-engagement one-time buyers — marketing budget is best split rather than applying a single blanket campaign.
  • Recency is the strongest early-warning signal for churn: customers drifting into high-recency, low-frequency territory should trigger an automated win-back flow.
  • Because Monetary and Frequency were log-transformed before scaling, a few very high spenders didn't dominate the clustering — worth doing a separate "big spender" outlier check if the business wants a bespoke top-1% VIP tier on top of these 4 segments.
